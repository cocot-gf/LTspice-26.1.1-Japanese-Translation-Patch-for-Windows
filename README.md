# LTspice 26.1.1 非公式日本語化パッチ

LTspiceのメニュー・ダイアログボックスを日本語化します。
LTspiceのバージョンは26.1.1専用です。

<img width="867" height="623" alt="aa" src="https://github.com/user-attachments/assets/57747141-fb34-4c2b-823e-97dfa9feb6d8" />


## 【使い方】
LTspice 26.1.1をインストールしたフォルダにパッチを置いて実行してください。
LTspice.exeが書き換えられ、古いファイルはLTspice.OLDとして保存されます。

## 【翻訳作業について】
大半のメニュー・ウィンドウは日本語化しましたが、表示の仕方がわからないものは
英語のままにしてあります。未翻訳や誤訳があれば、どういう手順で表示した画面かを
添えてご連絡いただければ対応します。

文字の書き換え作業は、バイナリディタを使って手作業で日本語の文字列に書き換え、
文字数が余った場合はUTF-16のゼロ幅スペース(0x200B)で埋めています。
文字数が足りない場合は、うまく収まるように言葉の言いかえで対応しています。
最終的な文字数は変わらないため、プログラムのサイズは同一になっています。
